# 极端天气运输保障知识

> 适用场景：校园极端天气演练期间，储备点向教学楼、图书馆、体育馆的物资运输。
> 涉及资源：车辆 V1 / V2，路线 route-A / route-B / route-C。

## 雨雪天气车辆调度原则

雨雪天气下车辆调度应遵循「降速、防滑、限载」三原则：车速不超过平时的一半，轮胎加装防滑措施，装载量不超过额定运力的 80%。路面结冰时优先安排状态为 AVAILABLE 的车辆，禁止安排故障（FAULT）车辆执行任务。

## 路线选择与时效评估

极端天气下优先选择耗时短、坡度小、不易积水的路线；若首选路线耗时超过剩余时限，应切换备选路线。路线评估要同时满足两个条件：路线状态为 available，且路线耗时不超过 remaining_time，二者缺一不可，否则判定该方案不可执行。

## 在途物资防护

运输饮用水和急救物资时应使用防水苫布覆盖车厢；易受冻物资在气温低于 0℃ 时应加装保温层。运输途中若发生车辆故障，应立即上报并启用备选车辆，同时评估在途物资是否需要回库或转运。

## 恶劣天气下签收取证要求

雨雪天气下签收取证存在困难，但「签收取证失败不等于物资未送达」。现场无法拍照或签字时，应记录签收人姓名、接收时间与数量作为替代证据，待条件允许后补传照片凭证。没有签收证据的投送单应标记为待验证，不得直接计入缺口。
